📍前言
#

R4 燒錄卡一直以來都是許多玩家在 Nintendo DS 上的首選，主要是價格真的相當低廉並且易於使用，遊戲的支持度也很不錯，功能也齊全。 我自己也是選擇用 R4 作為日常用卡，其主要原因還是因為其他更厲害的卡實在太貴了! 哈哈

在我去年 (2025) 購買圖中這張 R4 卡時價格已經低廉到隨意入手的地步，我記得當初只花了20幾塊人民幣吧? 把它運來日本的運費都比這張卡本身貴。

不過這張卡也還是有不少顯著缺點，例如相對耗電、時間炸彈 (新版韌體已移除)，以及介面醜等等。對我來說我最介意的其實是介面，因為我是外貿協會成員 XD

前陣子，我發現 EZFlash 它們家出了一款 EZ-FLASH Parallel，我查了各種資料覺得可能還不錯，價格也還可以，100 多人民幣的樣子。我 GBA 用的就是他們家的 Air 卡，覺得還不錯，所以想說買一張來試試看。

不過! 就在我找賣場準備下單的時候，我發現了一個更好的項目: DSPico。這是一個開源項目，用 RP2040 作為主控晶片。更重要的是，在 github 項目 出現不久後，我發現在 Aliexpress 上花 1500 日圓就可以買到一張!! 那還等什麼? 速速下單。

現在到手了，所以讓我分享一下使用心得。

什麼? 你說那 EZ-FLASH Parallel 呢? 阿那個之後再買來玩啦，現在先搞最新最便宜的 阿哈哈哈

📍這張卡有什麼特色 ?
#

1. 開源
#

之所以會對這張卡有強烈興趣，主要是因為我真的很好奇它實際用起來怎麼樣。作為一個軟硬體皆開源專案，可以想見如果各方面體驗真的都很不錯的話，廣大網友們就會開始為其開發各式各樣的酷炫功能，這是我相當期待的一個點。此外，它的主控晶片基於樹莓派 RP2040，我想這也是開發友好的原因之一。

有動力的話，我也想嘗試看看開發一些小應用，提升一點項目參與度。

我稍微瀏覽了一下 Reddit，版上的網友們也是對這個項目保持正面評價與態度，認為它之後可能取代 R4 當前的地位。

2. USB 接口
#

這張卡外觀上一個大特色，就是有 USB 接口。我看 Aliexpress 上有賣 micro 版本的也有 type C 版本的卡。

這是一個很酷的嘗試，因為向來大家都覺得燒錄卡這種東西用 SD 卡就好，還真沒想過在上面開一個 USB 孔出來，這也讓人更加期待有什麼更多更有趣的玩法。

可以參考這裡: dspico-usb-examples

透過 USB 向 SD 卡中傳輸檔案大概是其中唯一比較實用的了，下面實際使用心得會再提到這部分。

3. 省電
#

這個我還沒實際測試，但據網友們所說，這卡跟 R4 相比起來省電的多，這一點就很有利於會將機器帶出門玩的我了。

據我的經驗 R4 真的是蠻吃電的，希望這張卡能夠幫我解決此問題。

📍開箱與使用
#

我這個賣家給我的商品全部就如圖所示，除了燒錄卡本體之外還給我了一條數據線，以及兩張貼紙。我選擇貼了最一般樣式的貼紙上去。

1. 核心安裝與韌體更新
#

開箱之後我照著它的官方說明 (箱子左下的 QR code)，從 github 倉庫上下載了內核檔案放入 SD 卡中，並且更新了韌體。

更新韌體的方式很有意思: 當燒錄卡中沒有 SD 卡，同時用 USB 接上電腦後，會被識別成一個外接裝置。接著，把韌體檔案複製進去它就會自動更新了! 這是個新鮮的體驗，也是 USB 口的功能之一。

最後將 SD 卡插回，並把燒錄卡插入機器就可以了，很簡單。

2. 遊戲 ROM 與實際測試
#

在 SD 卡根目錄創建名為 games 的資料夾，將 ROM 檔案丟進去就可以了。遊戲啟動的速度也很快，玩了幾個遊戲都沒有太大問題。

上螢幕中的遊戲封面圖，可以到這個網站: PicoCover，直接選擇 SD 卡路徑就會自動處理了，相當方便。

與其它燒錄卡一樣，如果要玩 GBA 遊戲，去安裝 GBARunner3 就可以了，也可以順利運行。不過列表中顯示非英文標題有問題，我稍微檢索了一下也找不到好的解決方法。

GBARunner2 我沒有測試，不過按道理來說大概也沒問題。GBARunner3 相比 2 擁有更高的遊戲相容性，包括 「好狗狗星系」與「MOTHER」系列只有 3 能夠正常運行。

3. 主題安裝
#

接著是安裝主題的部分。

目前在 DS 機器上沒辦法即時切換主題。想要切換的話必需先下載主題檔案後，將資料夾放到 _pico\themes 中，然後修改 _pico/settings.json 檔案中的 theme 就可以了。

{
  "language": "english",
  "romBrowserLayout": "BannerList", 
  "romBrowserSortMode": "NameAscending",
  "theme": "BasicGray", // <- 這裡
  "lastUsedFilePath": "fat:/games/Newer Super Mario Bros. DS.nds",
  "fileAssociations": {}
}

主題檔案目前可以到這裡找，已經有些網友們有製作: https://gbatemp.net/download/categories/flashcart-files.85/

📍DSpico USB Examples
#

前言有說到，開發團隊有給 USB 接口開發了幾個範例應用程式，放在 這裡。

這幾個應用的用法都是將燒錄卡插入機器後，再用數據線接在燒錄卡上，是一種非常神奇的狀態。

倉庫中有做了 4 個範例應用:

  • mass-storage - Allows access to the DSpico micro SD card over USB (透過 USB 向 SD 卡中傳輸檔案)
  • usb-microphone - Makes the DSi/3DS work as a USB microphone for your PC (讓 DSi/3DS 作為麥克風讓 PC 使用)
    • Note: does not work with regular DS devices currently
  • usb-speaker - Makes the DS/DSi/3DS work as a USB speaker for your PC ( 讓 DS/DSi/3DS 作為 PC 喇叭使用 )
  • usb-video - Allows to use the camera of your DSi or 3DS on your PC via USB ( 讓 DSi/3DS 作為攝影機讓 PC 使用)

我也下載下來測試了一下，確實可以用，還蠻新奇的。

其中比較有實用價值的是透過 USB 向 SD 卡中傳輸檔案，但是! 我實際測試起來感覺傳輸檔案的速度挺慢，還不如直接取下 SD 卡傳輸。

麥克風、喇叭與攝影機功能也都有測試，可以用! 我還異想天開想說那可不可以接上 NS2 使用，但是經過我實際測試之後 -> X 不行。哈哈，可以的話就屬於祖孫連動了。

📍缺點: 目前功能太少
#

這是一個新專案，所以說功能還很少。

這邊所說的功能少是指連基礎功能都有缺乏，例如前面說到的無法在系統中直接改主題等。設定選單中目前只能設定排序與 Layout，就沒了! 對，就這樣。

金手指等高級功能就更別想了，一樣也是沒有。

不過以我的狀況來說我也不太用這些功能，還行啦!

📍總結
#

經過一連串的體驗，我認為當前這是一個有趣但還不太完整的專案。基礎燒錄卡的功能都很穩定，但就是細節功能與應用還有待大家來開發。我自己是很期待它未來的發展，目前是個好的開始。

我打算繼續用這張卡當主力卡一段時間，如果沒有大問題的話應該就會持續使用了，畢竟即使是單看耗電的部分，它也比 R4 優秀太多太多。

經驗與心得就是以上。感謝閱讀!
